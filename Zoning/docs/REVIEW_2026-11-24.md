These are mostly yes or no.

- **R01, 073 multiple family dwelling.** The Plan Area Statement allows it only on lots designated multi-density. The table can't store a condition. Should we store it as Allowed and put the condition in the notes? *Suggestion: yes.*
- **R03, 112 skiing facilities.** The Plan Area Statement lists "skiing facilities," but a staff note says that isn't a recognized use and would need an amendment. The row has no use name right now. Should we leave it blank, store "Skiing Facilities," or call it Downhill Ski Facilities?
